Bootstrap 5 compatibility fork

GWT Bootstrap Modern

A GwtBootstrap3-compatible update fork that keeps the familiar Java widget API while moving the bundled frontend stack onto Bootstrap 5, newer GWT, refreshed extras, and a TeaVM widget backend.

Open the GWT showcase View source on GitHub

What this fork is

  • Drop-in Maven modules for core and extras consumers.
  • Bootstrap 5 assets with compatibility CSS for Bootstrap 3-era class names.
  • The original showcase retained as a compile and behaviour gate.

TeaVM track

The TeaVM module now has a small widget API that mirrors GwtBootstrap3 concepts while using TeaVM DOM and Bootstrap interop. It is intentionally separate so GWT consumers are not forced into a runtime change.

Mobile note

This landing page is static and mobile-safe. The linked GWT showcase is preserved for compatibility testing and may expose older demo assumptions as the port progresses.
